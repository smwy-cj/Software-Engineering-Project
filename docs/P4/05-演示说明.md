# 演示说明

> 项目：CampusHub（青隅）校园互助服务平台 | 版本：v1.1.0 | 更新日期：2026-06-06

---

## 一、环境要求

| 组件 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 17+ | 后端运行环境 |
| Maven | 3.9+ 或Maven Wrapper | 后端构建和测试 |
| Node.js | 18+ | 前端开发与构建 |
| npm | 9+ | 前端依赖安装 |

当前演示环境使用H2内存数据库，无需安装MySQL。后端每次启动会重新初始化演示账号、树洞动态和搭子需求。

---

## 二、快速启动

### 2.1 启动后端

```bash
cd backend
mvn spring-boot:run
```

Windows且没有全局Maven时：

```powershell
cd backend
.\mvnw.cmd spring-boot:run
```

后端地址：

- API：`http://localhost:8080/api/v1`
- H2 控制台：`http://localhost:8080/h2-console`
- H2 JDBC URL：`jdbc:h2:mem:campushub`
- 用户名：`sa`
- 密码：留空

### 2.2 启动前端

```bash
cd frontend
npm install
npm run dev
```

前端地址：`http://localhost:3000`

前端使用 Hash 路由，页面地址示例：`http://localhost:3000/#/partner`

## 四、核心演示路径

### 路径一：找搭子完整流程

预计时长：5-7分钟

1. 使用小明账号 `13800138001 / Abc12345` 登录。
2. 进入 `/#/partner`，点击“发起搭子邀请”。
3. 填写类型、有效天数、最大人数和描述，例如“寻找一起备考六级的学习搭子”。
4. 发布成功后回到搭子列表。
5. 退出登录，使用小红账号 `13800138002 / Abc12345` 登录。
6. 在搭子列表找到小明发布的需求，点击“申请加入”。
7. 输入申请附言并提交。
8. 切回小明账号，进入 `/#/notifications` 查看申请通知。
9. 打开通知详情，接受或拒绝申请。
10. 进入 `/#/partner/match/{matchId}` 查看匹配详情；关系结束后可提交评价。

### 路径二：树洞发布与互动

预计时长：3-4分钟

1. 使用任意普通账号登录。
2. 进入 `/#/treehole`。
3. 使用分类、关键词、排序功能浏览动态。
4. 点击“写下心事”，选择分类并输入内容，可选择匿名发布。
5. 进入动态详情页 `/#/treehole/{postId}`。
6. 点赞或取消点赞，并发表评论。
7. 回到通知中心查看互动通知。

### 路径三：恋爱交友与心动

预计时长：3-5分钟

1. 使用普通用户登录。
2. 进入 `/#/love`。
3. 发布交友需求，填写描述和有效天数。
4. 使用另一个普通用户登录，浏览交友卡片。
5. 对非本人发布的需求点击“打个招呼”。
6. 如果双方互相心动，进入 `/#/love/matches` 查看匹配。

### 路径四：个人中心与反馈

预计时长：3分钟

1. 进入 `/#/profile`。
2. 查看实名认证状态和个人资料。
3. 查看“我的发布”和“我的申请”。
4. 在反馈区域选择类型并提交反馈。
5. 管理员可在后台处理该反馈。

### 路径五：管理员审核与用户管理

预计时长：4分钟

1. 使用管理员账号 `13800138000 / Admin123` 登录。
2. 进入 `/#/admin`。
3. 查看待审核内容列表和内容快照。
4. 对待审核内容执行通过或驳回。
5. 输入目标用户 ID，执行警告、禁言或封禁。
6. 查看反馈列表，填写处理意见并提交。

## 八、已知限制

1. H2 是内存数据库，后端重启后会重置演示数据。
2. 短信验证码为演示固定值 `123456`，生产环境需要接入真实短信服务。
3. 通用图片上传、实时聊天、智能匹配和管理统计为P2后续能力。
4. 内容审核当前以人工审核为主，敏感词服务只作为基础拦截能力。
5. 当前未提供公网部署地址，演示以本地启动为准。
