# 演示说明

> 项目：CampusHub（青隅）校园互助服务平台 | 版本：v1.0.0

---

## 一、环境要求

| 组件 | 版本要求 | 说明 |
|------|---------|------|
| JDK | 17+ | 后端运行环境 |
| Maven | 3.9+ | 后端构建工具 |
| Node.js | 18+ | 前端构建工具 |
| npm | 9+ | 前端包管理 |

> **注意：** 当前版本使用 H2 内存数据库，无需单独安装 MySQL。

---

## 二、快速启动

### 2.1 启动后端

```bash
cd backend
mvn spring-boot:run
```

后端启动后：
- API 地址：`http://localhost:8080/api/v1`
- H2 控制台：`http://localhost:8080/h2-console`（JDBC URL: `jdbc:h2:mem:campushub`）

### 2.2 启动前端

```bash
cd frontend
npm install
npm run dev
```

前端启动后：
- 访问地址：`http://localhost:3000`

## 四、核心演示路径

### 路径一：找搭子完整流程（核心演示）

**预计时长：** 5分钟

1. 使用 `13800138001` 登录（用户A — 小明）
2. 浏览搭子需求列表 → 点击"发布需求"
3. 填写搭子需求：类型=学习，描述="寻找一起备考六级的学习搭子"，发布
4. 退出登录，使用 `13800138002` 登录（用户B — 小红）
5. 浏览搭子需求列表 → 找到小明的需求 → 点击"申请匹配"
6. 输入附言："一起加油！"，提交申请
7. 说明：匹配申请已发送，等待发布者响应

### 路径二：树洞功能演示

**预计时长：** 3分钟

1. 使用任意账号登录
2. 进入"树洞"页面
3. 点击"发布动态" → 选择分类 → 输入内容 → 勾选"匿名发布" → 发布
4. 浏览树洞动态列表 → 点赞某条动态
5. 进入动态详情 → 发表评论

### 路径三：管理员功能演示

**预计时长：** 3分钟

1. 使用 `13800138000` 登录（管理员）
2. 进入"管理"页面
3. 查看待审核内容列表
4. 对某条内容点击"通过"或"驳回"
5. 查看反馈列表 → 处理用户反馈

### 路径四：注册新用户

**预计时长：** 2分钟

1. 点击"注册"
2. 填写手机号、用户名、密码
3. 短信验证码输入 `123456`（演示环境）
4. 注册成功 → 登录 → 进入个人中心
5. 填写实名认证信息 → 提交认证

## 七、已知限制

1. **H2 数据库**：当前使用内存数据库用于快速演示，生产环境需切换 MySQL
2. **短信验证码**：当前为 mock 实现（固定 "123456"），生产环境需接入真实短信服务
3. **图片上传**：P2 功能，当前暂未实现
4. **实时聊天**：WebSocket 未接入，聊天功能为预留接口
5. **内容审核**：敏感词过滤为预留功能，当前仅支持管理员人工审核
